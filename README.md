#  Project Overview

CSPF(Pet Family Care Service)는 반려동물 보호자가 전문가와 편리하게 상담할 수 있도록 개발한 종합 플랫폼입니다.

WebSocket(Socket.IO)을 활용한 실시간 채팅 시스템, 상담 예약 기능, AI 챗봇, JWT 기반 로그인 유지 기능을 구현하였으며, Android와 React Web 환경을 연동하여 실시간 데이터 동기화 및 사용자 중심 UI를 제공합니다.
