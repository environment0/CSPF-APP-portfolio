# CSPF
### Pet Family Care Service
### 반려동물을 위한 종합 케어 플랫폼

보험 · 병원 · 법률 상담 · AI 챗봇 · 실시간 채팅 서비스를

#  프로젝트 소개

**Pet Family Care Service(CSPF)**는 반려동물을 키우는 보호자를 위한 Android 애플리케이션입니다.

반려동물 보험, 병원 검색, 법률 상담 예약, AI 챗봇, 실시간 채팅 등
다양한 서비스를 하나의 앱에서 제공하는 것을 목표로 개발하였습니다.
