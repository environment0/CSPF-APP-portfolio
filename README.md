# CSPF - Pet Family Care Service

반려동물 보호자를 위한 법률 · 보험 · 의료 통합 플랫폼

CSPF(Pet Family Care Service)는 반려동물 보호자가 동물병원 예약, 보험, 법률 상담 서비스를 하나의 애플리케이션에서 편리하게 이용할 수 있도록 개발한 Android 기반 반려동물 종합 플랫폼입니다.

### 개발 목적

반려동물과 관련된 법률 · 보험 · 의료 서비스를 하나의 앱에서 이용할 수 있도록 변호사, 보험사, 수의사를 연결하는 반려동물 종합 플랫폼을 구축하였습니다.
기존에 각각 분리되어 있는 서비스를 하나의 플랫폼으로 통합하여 사용자가 전문가를 확인하고 상담을 예약하며, 실시간 채팅을 통해 편리하게 상담을 진행할 수 있도록 하는 것을 목표로 개발했습니다.

## Project Overview

CSPF는 반려동물 보호자가 동물병원 예약, 보험, 법률 상담 서비스를 하나의 애플리케이션에서 편리하게 이용할 수 있도록 개발한 Android 기반 종합 플랫폼입니다
**WebSocket(Socket.IO)**을 활용한 실시간 채팅 시스템과 JWT 기반 사용자 인증 및 로그인 유지 기능을 구현하여 사용자와 전문가가 원활하게 소통할 수 있는 환경을 구축했습니다.
또한 AI 챗봇 상담, 전문가 조회, 상담 예약, 실시간 채팅 및 이미지 전송 기능을 제공하여 사용자가 필요한 서비스를 하나의 애플리케이션에서 이용할 수 있도록 구현했습니다.

## 주요 기능

### 로그인 및 사용자 인증

JWT 기반 사용자 인증을 적용하여 로그인 상태를 유지하고 인증이 필요한 서버 API에 접근할 수 있도록 구현했습니다.

- JWT 기반 로그인 인증
- 로그인 후 Access Token 저장
- 사용자 로그인 상태 유지
- 인증 토큰을 이용한 서버 API 요청

---

### 전문가 조회

서버 REST API를 통해 등록된 전문가 정보를 조회하고 사용자가 원하는 상담 전문가를 선택할 수 있도록 구현했습니다.

- 서버 API를 이용한 전문가 목록 조회
- 전문가 상세 정보 확인
- 변호사 등 상담 전문가 선택
- 사용자 목적에 맞는 전문가 연결

---

### 상담 예약

사용자가 상담을 원하는 전문가와 날짜 및 시간을 선택하여 상담을 예약할 수 있도록 구현했습니다.

#### 예약 프로세스

```text
전문가 선택
    ↓
날짜 선택
    ↓
시간 선택
    ↓
상담 사유 작성
    ↓
예약 요청
```

사용자가 입력한 예약 정보를 REST API를 통해 서버로 전달하여 상담 예약을 처리합니다.

---

### 실시간 채팅

Socket.IO를 이용하여 사용자와 상담사 간의 실시간 양방향 채팅 기능을 구현했습니다.

- 채팅방 목록 조회
- 채팅방 입장
- 실시간 메시지 송수신
- 사용자와 상담사 간 실시간 상담
- 서버와 클라이언트 간 메시지 동기화

---

### 이미지 전송

상담 과정에서 텍스트뿐만 아니라 필요한 사진이나 자료를 전달할 수 있도록 이미지 전송 기능을 구현했습니다.

- 이미지 선택
- Multipart 방식 이미지 업로드
- 서버 이미지 저장
- 채팅 메시지에 이미지 표시

---

### AI 챗봇

사용자가 간단한 질문을 빠르게 해결할 수 있도록 AI 챗봇 기능을 적용했습니다.

- 사용자 질문 입력
- 챗봇 자동 응답
- 상담이 필요한 경우 전문가 상담 기능과 연계

## 프로젝트를 통해 경험한 내용

이 프로젝트를 통해 단순한 화면 구현뿐만 아니라 클라이언트와 서버가 데이터를 주고받는 전체적인 서비스 구조를 경험했습니다.
특히 Socket.IO를 활용하면서 일반적인 REST API 요청과 달리 서버와 클라이언트가 연결된 상태에서 데이터를 실시간으로 송수신하는 양방향 통신 구조를 이해할 수 있었습니다.
또한 JWT를 이용한 사용자 인증 및 토큰 관리, REST API를 이용한 전문가 조회 및 예약 처리, Multipart를 이용한 이미지 업로드 등 실제 서비스에서 활용되는 다양한 기능을 구현했습니다.
Android 애플리케이션뿐만 아니라 React Web과 Node.js 서버가 함께 동작하는 팀 프로젝트를 진행하면서 각 플랫폼 간 데이터 형식과 API 규격을 맞추는 과정의 중요성을 경험했습니다.
또한 Git과 GitHub를 활용하여 팀원들과 코드를 관리하고 기능별 개발 내용을 공유하면서 협업 개발 및 버전 관리 과정을 경험했습니다.

##  프로젝트 핵심

**반려동물 보호자와 의료 · 보험 · 법률 전문가를 하나의 플랫폼에서 연결**

CSPF는 여러 곳에 분산되어 있는 반려동물 관련 서비스를 하나의 애플리케이션으로 통합하고, **예약 → 상담 → 실시간 채팅**으로 이어지는 사용자 중심의 서비스 흐름을 구현한 프로젝트입니다.
