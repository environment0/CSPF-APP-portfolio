#  Project Overview

CSPF(Pet Family Care Service)는 반려동물 보호자가 동물병원 예약, 보험, 법률 상담 서비스를 하나의 애플리케이션에서 편리하게 이용할 수 있도록 개발한 Android 기반 종합 플랫폼입니다.
사용자는 AI 챗봇을 통한 상담과 실시간 채팅 기능을 이용할 수 있으며, 상담 예약 서비스를 통해 전문가와 원활하게 소통할 수 있습니다.
본 프로젝트에서는 WebSocket(Socket.IO)을 활용한 실시간 채팅 시스템, JWT 기반 사용자 인증 및 로그인 유지 기능을 구현하여 안정적인 서비스 환경을 구축했으며, 사용자 중심의 UI/UX를 적용하여 편리한 사용 경험을 제공했습니다.
